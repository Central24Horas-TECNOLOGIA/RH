# Menus

## Menu lateral

O menu lateral e a principal estrutura de navegacao. Ele tem grupos expansivos para Processos, Relatorios e Configuracoes. O estado ativo e indicado por classe visual e `aria-current`.

| Menu | Subitens |
| --- | --- |
| Inicio | nenhum |
| E-mails | nenhum |
| Processos | Processos, Processos encerrados, Provas e Resultados |
| Entrevistas | nenhum |
| Banco de Talentos | nenhum |
| Relatorios | Analise de candidatos, Candidatos |
| Configuracoes | Usuarios, Perfis e permissoes, Regras reutilizaveis, Logs |

## Menu do usuario

Acionado no avatar/topbar. Exibe:

- Configuracoes, quando permitido.
- Sair.

## Menus secundarios

| Tela | Menu | Funcao |
| --- | --- | --- |
| Processos | Mais acoes | acoes contextuais da linha |
| Detalhe processo | Abas | alternar candidatos, aprovados, reprovados, dossie, entrevistas, provas, historico |
| Configuracoes | Abas/submenus | alternar usuarios, perfis, regras e logs |
| Logs | Item expansivel | abrir detalhes do evento |
