# Processos seletivos

## Etapas do processo seletivo

| Etapa | Tela | Dados | Regras |
| --- | --- | --- | --- |
| Cadastro | Novo processo | vaga, vagas, encerramento, operacao, trilha, nota | processo nasce Aberto |
| Divulgacao | Detalhe > Compartilhar vaga | slug/token publico | depende de link ativo |
| Captacao | E-mail / candidatura / candidato manual | dados e CV | pode vir de e-mail, banco ou cadastro |
| Triagem | Analise de CV / Candidatos | score, classificacao, observacao | RH decide manualmente |
| Qualificacao | Detalhe processo | status Qualificado | habilita entrevista |
| Entrevista | Entrevistas / Detalhe | slot, data, status | depende de disponibilidade |
| Prova | Provas e resultados / Conecta Provas | codigo, questoes, nota | resultado alimenta decisao |
| Decisao | Detalhe / Ficha | aprovado, eliminado, banco | status terminal |
| Encerramento | Processos | processo Encerrado | bloqueia movimentacoes indevidas |
