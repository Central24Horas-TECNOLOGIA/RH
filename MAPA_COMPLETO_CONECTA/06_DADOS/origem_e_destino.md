# Origem e destino

| Dado | Origem | Destino final |
| --- | --- | --- |
| Curriculo de e-mail | caixa de entrada | analise, ficha, processo ou banco |
| Dados extraidos do CV | analise automatica | ficha/candidato/processo |
| Processo | cadastro RH | detalhe, filtros, relatorios, prova, entrevista |
| Slot | entrevistas | agenda e agendamento |
| Entrevista | agendamento | status candidato e historico |
| Prova | geracao | portal publico, resultado e historico |
| Decisao RH | detalhe/ficha | status final e logs |
| Usuario | configuracoes | autenticacao/permissoes |
| Catalogo | regras reutilizaveis | selects, motivos, status, modelos |
| Log | acoes do sistema | auditoria/exportacao |
