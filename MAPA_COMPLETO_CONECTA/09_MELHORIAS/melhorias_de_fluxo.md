# Melhorias de fluxo

| Fluxo | Melhoria | Beneficio |
| --- | --- | --- |
| E-mail -> processo | pre-visualizar dados antes de vincular | evita cadastro errado |
| Analise CV | exigir revisao humana antes de status automatico | reduz falso negativo |
| Processo -> entrevista | mostrar slots elegiveis e motivo de bloqueio | agilidade |
| Entrevista -> decisao | checklist pos-entrevista | padroniza decisao |
| Prova -> resultado | explicar alertas e pendencias | clareza |
| Banco -> processo | detectar duplicidade no processo | evita repeticao |
| Usuario/perfil | comparar permissoes antes/depois | governanca |
| Encerramento | checklist de pendencias | evita fechar processo ativo |
