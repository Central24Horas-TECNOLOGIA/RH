# Matriz regras e fluxos

| Regra | Fluxos afetados |
| --- | --- |
| Login obrigatorio | todos os fluxos internos |
| Permissao por perfil | menu, usuarios, logs, candidatos, processos |
| Processo aberto/encerrado | candidato, entrevista, prova, encerramento |
| Nota de corte | criacao processo, resultado, triagem |
| Candidato qualificado | agendamento, prova |
| Status terminal | aprovacao, eliminacao, banco, relatorios |
| Motivo obrigatorio | eliminacao, cancelamentos |
| Slot/capacidade | entrevistas e reagendamento |
| Prova disponivel/finalizada/cancelada | Conecta Provas, resultados |
| Logs de auditoria | login, exportacao, configuracoes, acoes criticas |
| Catalogos ativos | motivos, status, documentos, e-mails |
