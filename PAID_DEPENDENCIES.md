## Regra de validação antes de qualquer item virar "REQUIRES_PROCUREMENT" de fato (regra 48)

Antes de recomendar pagamento para qualquer item acima, confirmar em ordem: (1) existe solução open source? (2) existe solução própria/interna? (3) existe recurso Microsoft 365 já contratado que resolve? (4) existe ferramenta gratuita? (5) existe free tier suficiente? (6) dá para adiar? (7) dá para criar uma abstração e decidir depois? Nenhum item desta lista pulou essa checagem — cada linha já registra a alternativa gratuita avaliada.
