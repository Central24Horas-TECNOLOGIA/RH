# 3. CORREÇÃO Nº 1 — PROCESSOS SELETIVOS: ELIMINAR E BANCO

## PROBLEMA

Na tela:

**Processos Seletivos**

Existem ações nos candidatos:

* `Eliminar`
* `Banco`

Atualmente, ao clicar nessas opções, aparentemente nada acontece.

Foi identificado nos logs o seguinte erro:

```text
PUT /process-candidates/CP-20260724-80282C/status HTTP/1.1
422 Unprocessable Content
```

E:

```text
Falha de validação na API:
[
  {
    'type': 'int_parsing',
    'loc': ['path', 'id_registro'],
    'msg': 'Input should be a valid integer, unable to parse string as an integer',
    'input': 'CP-20260724-80282C'
  }
]
```

O problema é extremamente claro:

O frontend está enviando:

```text
CP-20260724-80282C
```

para um parâmetro da API chamado:

```text
id_registro
```

mas o backend está esperando um:

```text
integer
```

Portanto, existe uma incompatibilidade entre o identificador usado pela interface e o identificador esperado pela API.

---

### ELIMINAR

Ao clicar em:

```text
Eliminar
```

o candidato deve ser eliminado do processo seletivo **conforme a regra funcional já existente no sistema**.

Não inventar um novo comportamento.

Utilizar a lógica já definida no projeto.

### BANCO

Ao clicar em:

```text
Banco
```

o candidato deve ser transferido para:

```text
Banco de Talentos
```

conforme a lógica originalmente definida.

O candidato não deve simplesmente desaparecer.

A ação deve efetivamente executar a transferência para o Banco de Talentos.

